개인정보처리방침

시행일: 2026년 11월 12일

우리 가족 체크노트(이하 ‘서비스’)는 초대받은 세 가족이 임신·출산·육아 준비물과 일정, 예산을 각 가족 공간에서 관리하기 위한 개인용 웹 서비스입니다. 운영자는 서비스 제공에 필요한 데이터를 최소한으로 취급합니다.

1. 입력하는 정보와 목적

  • 가족 식별 코드, 직접 입력한 아이 이름·출생일(선택), 준비물·할 일·일정·예산·지출·메모·선물 및 제공자 정보: 가족별 체크리스트 관리
  • 최초 등록 초대 코드의 검증값, PIN으로부터 파생된 인증 검증값 및 암호화용 salt: 최초 등록과 잠금 해제
  • 업데이트 시각, 데이터 버전 번호, 암호화된 저장 데이터: 동기화와 충돌 방지

2. Google 계정 권한의 사용

Google Sheets OAuth 권한은 서비스 운영자의 서버용 Google 계정에서 별도의 암호문 전용 스프레드시트에 접근하기 위해 사용됩니다. 일반 가족 사용자에게는 Google 계정 로그인이나 Google Sheets 권한 승인을 요구하지 않습니다. 서비스 소스가 사용하는 권한은 https://www.googleapis.com/auth/spreadsheets이며, 저장소에는 기존 자산관리 시트나 다른 문서의 접근 정보가 없습니다.

3. 암호화·저장 위치

앱은 브라우저에서 PBKDF2와 AES-GCM으로 개인 입력 내용을 암호화한 뒤 Google Apps Script를 통하여 Google Sheets의 APP_DB 탭에 암호문으로 저장하도록 설계되었습니다. 편집 대기 및 오프라인 복원을 위해 기기의 로컬 저장소에도 암호문을 보관할 수 있습니다. PIN 원문은 서버에 저장하지 않습니다.

중요: PIN은 4자리 숫자여서 암호문 유출이나 자동 대입 공격에 강한 보호 수단은 아닙니다. 또한 소스코드 수정 권한을 가진 운영자는 이후 배포 코드를 변경할 수 있으므로 운영자에게도 절대적으로 내용이 보이지 않는다고 보장하지 않습니다.

4. 공개 범위와 외부 서비스

GitHub Pages에는 웹앱 소스와 일반적인 예시 항목만 공개합니다. 가족이 입력한 값은 공개 GitHub 소스에 게시하지 않습니다. 초대받지 않은 방문자도 앱 페이지 자체는 열 수 있지만, 가족 데이터 열람·수정에는 해당 가족의 등록 정보가 필요합니다.

  • Google Sheets·Apps Script: 암호화된 가족 데이터의 저장·조회·동기화
  • GitHub Pages: 공개 앱 화면과 정책 페이지 호스팅
  • 브라우저 로컬 저장소: 암호화된 임시 기록과 동기화 대기

Google과 GitHub 등 플랫폼 제공자는 각자의 개인정보 처리방침에 따라 접속 로그·네트워크 정보를 처리할 수 있습니다. 서비스에는 별도의 광고 추적·분석 SDK를 포함하지 않았습니다.

5. 보관·정정·삭제

계정 등록 후의 기록은 사용자가 수정하거나 삭제할 때까지 유지됩니다. 기기의 브라우저 데이터를 지우면 해당 기기 로컬 기록이 삭제되지만 서버 DB에 저장된 암호문은 자동 삭제되지 않습니다. 서버의 가족 기록 삭제나 전반적인 데이터 관련 요청은 운영자에게 문의할 수 있습니다. PIN을 분실하면 저장된 암호문을 복원할 수 없을 수 있습니다.
